# Planilla Demo CSS

Crea un MVP completo, funcional y en español para el Caso 7: CSS y empleadores. Usa los documentos adjuntos como especificación y construye una landing page profesional más una aplicación demo de prevalidación de planillas con datos sintéticos, sin usar datos personales reales ni afirmar aprobación oficial de la CSS. Incluye: carga CSV de demostración con plantilla descargable, procesamiento de validaciones de estructura, identidad, salario, consistencia e histórico; resultados clasificados en válido, alerta y error bloqueante; flujo de corrección que genere una nueva versión; tablero con métricas; detalle de planilla y hallazgos; historial/auditoría; catálogo de reglas y matriz normativa; estados RECIBIDA, EN_VALIDACION, CON_ERRORES, EN_REVISION, PREVALIDADA. Usa datos genéricos realistas de empleadores y trabajadores ficticios. Incluye el aviso claro de que PREVALIDADA es resultado interno y no aprobación institucional. Diseña navegación por secciones y una buena experiencia responsive. Da créditos visibles en landing y sección 'Equipo' a Pablo Sánchez (Backend Python y arquitectura técnica), Alberto Davis (Seguridad y DevOps), Daniel Domínguez (Product Owner, análisis de negocio, Scrum Master y calidad). Considera el enfoque indicado en la imagen: Python, Apache JMeter, Nikto y Ansible como herramientas/compatibilidad documentada en una sección de arquitectura y calidad, pero no simules pruebas de seguridad reales ni afirmes integraciones inexistentes. Prioriza una demo totalmente navegable y que las validaciones funcionen localmente con el archivo de ejemplo. Habilita Lovable Cloud si hace falta persistencia, pero la demo debe funcionar también con datos de ejemplo. Usa un estilo institucional moderno que no suplante la marca oficial CSS. Adjuntos: ambos DOCX de requisitos y la imagen de tecnologías.
